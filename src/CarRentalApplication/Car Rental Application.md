# Car Rental Application

## Overview
The Car Rental Application is an ASP .NET Core Web Api application designed to manage a car rental system. The application follows object-oriented principles and it's mainly focused on Dependency Injection and Inversion of Control.

## Initial Setup
The applications uses Swagger to let the user interacting with a basic REST API. At startup, a simple interface provided by the Swagger can be used to make simple HTTP calls that handle the business logic of the application.

Following classes are already integrated in the project:
- **CarController**: ApiController used to manage Car operations.
- **CustomerController**: ApiController used to manage Customer operations.
- **RentalController**: ApiController used to manage Rental operations.

## Requirements
- The project must use `EF Core` to handle database operations.
- Implement following Entities:
    - The `Car` class represents a Car with the following properties:
        - `Id` (long): The unique identifier for the Car, autogenerated and cannot be updated.
        - `LicensePlate` (string): The license plate of the car.
        - `IsRented` (bool): A flag indicating if the Car is currently rented.
    - The `Customer` class represents a Customer with the following properties:
        - `Id` (long): The unique identifier for the Car, autogenerated and cannot be updated.
        - `Name` (string): The name of the customer.
    - The `Rental` class represents a Rental operation with the following properties:
        - `Id` (long): The unique identifier for the Car, autogenerated and cannot be updated.
        - `CarId` (long): The Id of a rented car.
        - `CustomerId` (long): The Id of a Customer that rented a Car.
        - `RentalDate` (DateTime): The date of a rental.
        - `ReturnDate` (DateTime?): The return date of a rental.
- Feel free to extend each Entity with additional properties.
- Implement the class `CarRentalContext` to set up the database context, using the entities defined in the previous step. Consider seeding the database with some dummy data for each entity.
- Define the ConnectionString of the database in the file appsettings.json and update the class Program.cs to properly fetch the ConnectionString and setup the DBContext.
- Implement following `Services` and their corresponding `Interfaces`:
    - The `CarService` class handles operations related to the Car.
    - The `CustomerService` class handles operations related to the Customer.
    - The `RentalService` class handles operations related to the Rental.
- Each Service must implement the methods `IEnumerable<Entity> GetAll()` and `Entity GetById(long id)`
- Only the RentalService must also implements the methods `void RentCar(Car car, Customer customer)` and `void ReturnCar(Car car)`. 
- Consider implementing a `ServiceBase` class, inherited from each Service, where the CarRentalContext is injected.
- Each Service must be injected in the respective Controller in order to perform an HTTP call using the Swagger. Use the HTTP endpoints provided in each Controller to perform the proper operation.
- **NB**: For the methods `RentCar` and `ReturnCar` you can skip for now the creation of the HTTP endpoints in the controller. Just focusing on the logic inside the RentalService.
- Finalize the assessment implementing, in each Service, also the basic write operations `(Insert/Update/Delete)`.
